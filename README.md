# Sales Insights Dashboard – Power BI

## Overview

This project is an end-to-end Sales Insights Dashboard developed in **Power BI** using **SQL** and **Excel** data. The dashboard transforms raw sales data into meaningful business insights through interactive visualizations, helping stakeholders monitor sales performance and make informed decisions.

## Features

* Connected Power BI to a MySQL database and imported sales data.
* Performed data cleaning and transformation using **Power Query**.
* Built a **star schema** data model for efficient reporting.
* Created custom **DAX measures** for key business metrics.
* Designed interactive dashboards with filters and slicers.
* Analyzed **revenue trends**, **sales performance**, **customer insights**, and **market performance**.

## Tools & Technologies

* Power BI
* MySQL
* Power Query
* DAX
* Microsoft Excel

## Key Insights

* Monitored revenue across different markets and time periods.
* Identified top-performing customers and products.
* Compared sales performance across regions.
* Enabled interactive analysis using dynamic filters and drill-down reports.
